# Setup

## Prerequisites

- Node.js 18+
- pnpm
- Python 3.11+
- PostgreSQL
- Redis

## Frontend

```bash
pnpm install
pnpm dev
```

## Backend

```bash
python3 -m venv venv
./venv/bin/pip install -r backend/requirements.txt
./start.sh
```

## Local endpoints

- Frontend: `http://localhost:3000`
- Backend: `http://localhost:8000`
